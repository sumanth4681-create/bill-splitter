split.py · prd › Claiming Items, Split Summary · subagent experiment

compute_split(items, people, claims, tax_cents, tip_cents, overrides) → Summary. Pure, with no I/O.

  • Claimed item → divided among its claimers only
  • Unclaimed item → divided among all, labeled unclaimed
  • Tax and tip → divided equally among all
  • Rounding: amount // n each, and the first amount % n people get +1¢ (so $10 ÷ 3 = 334 / 333 / 333)
  • final_cents = override or computed; matches_receipt ignores overrides

Invariant test: for any input, Σ computed = items + tax + tip.

Built by a subagent given only this section plus Contracts. Did the lean context suffice?

ocr.py · prd › Receipt Upload and Reading

read_receipt(image_bytes, mime_type) → ParsedReceipt

  • sha256 of the image → if fixtures/{hash}.json exists, replay it; otherwise call Document AI and save
  • map_expense_document(doc) is a separate pure function, tested on saved fixtures
  • line_item → item; total_tax_amount, total_amount, supplier_name
  • No line items → UnreadableReceipt → 422 "Upload a clear image"

Verify on the first live response: exact entity names, and whether there's a tip entity (fallback: total − items − tax).

storage.py + SQLite · prd › History
bills   (id, name, created_at, image_hash, tax_cents, tip_cents, receipt_total_cents)
items   (id, bill_id, position, name, quantity, price_cents)
people  (id, bill_id, position, name, override_cents NULL)
claims  (item_id, person_id)  PK(item_id, person_id)

The summary is never stored. It's recomputed on every request, so it's always current.

Streamlit screen · prd › Screens and Layout

Tabs: Upload, History. Bill view: name → names + person dropdown → summary (totals warning if mismatched) → items with checkboxes and claimers listed under each.

Holds only the current bill and selected person in session_state. Muted sage theme in .streamlit/config.toml, with st.toast for feedback.

Failure modes

  • Blurry photo / not a receipt → "Upload a clear image of the receipt"
  • Google not configured → "Receipt reader isn't configured. Check .env." (replay mode still works)
  • Backend down → "Backend isn't running. Start it with uvicorn…"
  • Totals disagree → a warning pointing to a misread row
